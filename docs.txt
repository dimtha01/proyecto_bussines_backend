# API DE ARCHIVOS POR PROYECTO - Documentación de Uso
====================================================

## RESUMEN GENERAL
-----------------
Sistema de gestión de archivos asociados a proyectos. Permite subir, listar,
descargar y eliminar archivos con soporte para imágenes, PDFs y documentos.

## RUTAS DISPONIBLES
-------------------

### 1. SUBIR ARCHIVOS A UN PROYECTO
POST /api/archivos/proyectos/:projectId/upload

Descripción: Sube uno o varios archivos y los asocia a un proyecto específico.

Parámetros de URL:
  - projectId: ID del proyecto (obligatorio)

Body (FormData):
  - files: Archivo(s) a subir (campo name="files")
    * Mínimo: 1 archivo
    * Máximo: 10 archivos por solicitud
    * Tamaño máximo: 50 MB por archivo

Tipos de archivo permitidos:
  - Imágenes: JPEG, PNG, WebP, GIF
  - Documentos PDF: application/pdf
  - Documentos de Office:
    * Word (.doc, .docx)
    * Excel (.xls, .xlsx, .xlsm, .xlam)
    * CSV

Respuesta exitosa (201):
{
  "message": "X archivo(s) guardados correctamente.",
  "files": [
    { "nombre": "documento.pdf", "tipo": "pdf" },
    { "nombre": "imagen.jpg", "tipo": "image" }
  ]
}

Errores comunes:
  - 400: No se subieron archivos o tipo no permitido
  - 404: Proyecto no encontrado
  - 500: Error interno del servidor

Ejemplo cURL:
curl -X POST http://localhost:3000/api/archivos/proyectos/1/upload \
  -F "files=@/ruta/al/archivo.pdf" \
  -F "files=@/ruta/al/otro.docx"

Ejemplo JavaScript/Fetch:
const formData = new FormData();
formData.append('files', fileInput.files[0]);
formData.append('files', fileInput.files[1]);

fetch('http://localhost:3000/api/archivos/proyectos/1/upload', {
  method: 'POST',
  body: formData
})
.then(res => res.json())
.then(data => console.log(data));


### 2. LISTAR ARCHIVOS DE UN PROYECTO
GET /api/archivos/proyectos/:projectId/files

Descripción: Obtiene la lista completa de archivos asociados a un proyecto.

Parámetros de URL:
  - projectId: ID del proyecto (obligatorio)

Respuesta exitosa (200):

  "archivos": [

      "nombre": "documento-importante.pdf",
      "tipo": "pdf",

    },
    {
      "id": 124,
      "nombre": "diagrama.png",

      "urlDescarga": "/api/archivos/descargar/124",
      "ruta_archivo": "http://localhost:3000/uploads/image/diagrama-1234567891.png"
    }

Errores comunes:
  - 404: Proyecto no encontrado
  - 500: Error interno del servidor

Ejemplo cURL:
curl http://localhost:3000/api/archivos/proyectos/1/files

Ejemplo JavaScript/Fetch:

  .then(res => res.json())

### 3. DESCARGAR UN ARCHIVO
GET /api/archivos/descargar/:fileId

Descripción: Descarga un archivo específico por su ID. El navegador recibirá
el archivo como descarga (attachment).

Parámetros de URL:
  - fileId: ID del archivo (obligatorio)

Respuesta:
  - Archivo binario con header Content-Disposition para descarga
  - Soporta nombres con acentos y caracteres especiales (UTF-8)

Errores comunes:
  - 400: Ruta inválida o archivo es URL externa
  - 404: Archivo no encontrado (en BD o físicamente)
  - 500: Error interno del servidor

Ejemplo cURL:
curl -O -J http://localhost:3000/api/archivos/descargar/123

Ejemplo JavaScript/Fetch:
fetch('http://localhost:3000/api/archivos/descargar/123')
  .then(res => res.blob())
  .then(blob => {
    const url = window.URL.createObjectURL(blob);
    const a = document.createElement('a');
    a.href = url;
    a.download = 'archivo.pdf';
    a.click();
  });


### 4. ELIMINAR UN ARCHIVO
DELETE /api/archivos/eliminar/:fileId

Descripción: Elimina un archivo de la base de datos y del sistema de archivos.

Parámetros de URL:
  - fileId: ID del archivo (obligatorio)

Respuesta exitosa (200):
{
  "message": "Archivo eliminado correctamente",
  "archivoEliminado": "documento.pdf"
}

Notas importantes:
  - Si el archivo es local, también se elimina físicamente del disco
  - Si el archivo es una URL externa, solo se elimina el registro de BD
  - La operación es irreversible

Errores comunes:
  - 404: Archivo no encontrado
  - 500: Error interno del servidor

Ejemplo cURL:
curl -X DELETE http://localhost:3000/api/archivos/eliminar/123

Ejemplo JavaScript/Fetch:
fetch('http://localhost:3000/api/archivos/eliminar/123', {
  method: 'DELETE'
})
.then(res => res.json())
.then(data => console.log(data));


## CONFIGURACIÓN Y ALMACENAMIENTO
---------------------------------

### Estructura de directorios
Los archivos se organizan automáticamente por tipo en la carpeta "uploads/":

uploads/
├── image/          # Imágenes (jpg, png, webp, gif)
├── pdf/            # Documentos PDF
└── document/       # Documentos de Office (Word, Excel, CSV)

### Nomenclatura de archivos
Los archivos son renombrados automáticamente con slugify:
  - Nombre original: "Mi Documento Importante (2024).pdf"
  - Nombre guardado: "mi-documento-importante-2024-1234567890.pdf"

Formato: {nombre-slugificado}-{timestamp}{extension}

### Variables de entorno
UPLOADS_ROOT: Ruta raíz para almacenamiento (opcional)
  - Si no se define, usa: ./uploads/ (relativo al directorio del proyecto)
  - Recomendado para producción: definir ruta absoluta

Ejemplo .env:
UPLOADS_ROOT=/var/www/app/uploads


## BASE DE DATOS
---------------

### Tabla: archivos
Campos principales:
  - id: ID único del archivo (PRIMARY KEY)
  - id_proyecto: ID del proyecto asociado (FOREIGN KEY)
  - nombre_archivo: Nombre original del archivo
  - ruta_archivo: Ruta relativa del archivo (ej: "uploads/pdf/archivo.pdf")
  - tipo_archivo: Tipo de archivo ('image', 'pdf', 'document')
  - fecha_creacion: Timestamp de creación


## SEGURIDAD Y VALIDACIONES
---------------------------

### Límites de subida
  - Tamaño máximo: 50 MB por archivo
  - Cantidad máxima: 10 archivos por solicitud
  - Tipos permitidos: Solo los especificados en "Tipos de archivo permitidos"

### Protección contra path traversal
El sistema implementa validación de rutas para evitar accesos no autorizados:
  - Las rutas se resuelven siempre dentro de UPLOADS_ROOT
  - Se detecta y rechaza intentos de path traversal (../)

### Validación de proyectos
  - Se verifica que el proyecto existe antes de subir/listar archivos
  - Se retorna 404 si el proyecto no existe

    console.log('Archivos subidos:', result);

    console.error('Error al subir:', error);
  }
});

## NOTAS IMPORTANTES
-------------------

1. Los archivos se renombran automáticamente para evitar conflictos
2. Las rutas almacenadas en BD son relativas para portabilidad
3. El sistema soporta URLs externas (no se descargan del servidor)
4. Los nombres de archivo con caracteres especiales usan encoding UTF-8
5. Si se elimina un archivo local, se intenta borrar también del disco físico


## CÓDIGOS DE ESTADO HTTP
--------------------------

- 200: Operación exitosa (listar, eliminar)
- 201: Recurso creado (subir archivos)
- 400: Solicitud inválida (sin archivos, tipo no permitido, ruta inválida)
- 404: Recurso no encontrado (proyecto o archivo)
- 500: Error interno del servidor

## RESUMEN GENERAL
-----------------
Sistema de notificaciones en tiempo real que se crea automáticamente cada vez
que se sube un archivo a un proyecto. Las notificaciones se guardan en la
base de datos y se envían a todos los clientes conectados vía WebSocket.


## CONFIGURACIÓN PREVIA
----------------------

1. Ejecutar el script SQL para crear la tabla de notificaciones:
   mysql -u tu_usuario -p tu_base_datos < db/notificaciones.sql

2. Iniciar el servidor (WebSocket se inicia automáticamente):
   npm run dev


## ENDPOINTS API REST
-------------------

BASE URL: http://localhost:3000/api/notificaciones

### 1. OBTENER TODAS LAS NOTIFICACIONES
GET /api/notificaciones

Query Params (opcionales):
  - proyectoId: (number) - Filtrar por proyecto específico

## EVENTOS WEBSOCKET
-------------------

Servidor WebSocket: http://localhost:3000

### EVENTOS QUE ENVÍA EL SERVIDOR (escuchar en el cliente):

1. nueva_notificacion
   - Emitido cuando se crea CUALQUIER notificación
   - Recibido por TODOS los clientes conectados

2. notificacion_proyecto
   - Emitido cuando se crea una notificación para un proyecto específico
   - Solo recibido por clientes unidos a la sala de ese proyecto

Datos recibidos en ambos eventos:
{
  "id": 1,
  "id_proyecto": 5,
  "titulo": "Archivos subidos",
  "mensaje": "Se han subido 2 archivo(s) al proyecto.",
  "tipo": "archivo_subido",
  "leida": false,
  "datos": { "archivos": ["documento.pdf"] },
  "fecha_creacion": "2025-01-15T10:30:00.000Z"
}

### EVENTOS QUE ENVÍA EL CLIENTE (emitir al servidor):

1. unir_proyecto
   - Une al cliente a la sala de un proyecto específico
   - Parámetro: projectId (number)

2. salir_proyecto
   - Saca al cliente de la sala de un proyecto
   - Parámetro: projectId (number)

// hooks/useNotifications.js
import { useState, useEffect } from 'react';
import { io } from 'socket.io-client';

const socket = io('http://localhost:3000');

export const useNotifications = (projectId) => {
  const [notifications, setNotifications] = useState([]);
  const [unreadCount, setUnreadCount] = useState(0);

  useEffect(() => {
    // Unirse a la sala del proyecto
    if (projectId) {
      socket.emit('unir_proyecto', projectId);
    }

    // Escuchar notificaciones globales
    socket.on('nueva_notificacion', (notification) => {
      setNotifications(prev => [notification, ...prev]);
      setUnreadCount(prev => prev + 1);
      mostrarNotificacionNativa(notification);
    });

    // Escuchar notificaciones del proyecto
    socket.on('notificacion_proyecto', (notification) => {
      setNotifications(prev => [notification, ...prev]);
    });

    // Cargar contador inicial
    fetchUnreadCount();

    return () => {
      socket.off('nueva_notificacion');
      socket.off('notificacion_proyecto');
      if (projectId) {
        socket.emit('salir_proyecto', projectId);
      }
    };
  }, [projectId]);

  const fetchUnreadCount = async () => {
    const response = await fetch('http://localhost:3000/api/notificaciones/contar-no-leidas');
    const data = await response.json();
    setUnreadCount(data.noLeidas);
  };

  const markAsRead = async (notificationId) => {
    await fetch(`http://localhost:3000/api/notificaciones/${notificationId}/leer`, {
      method: 'PATCH'
    });
    setUnreadCount(prev => Math.max(0, prev - 1));
  };

  const markAllAsRead = async () => {
    await fetch('http://localhost:3000/api/notificaciones/marcar-todas-leidas', {
      method: 'PATCH',
      headers: { 'Content-Type': 'application/json' }
    });
    setUnreadCount(0);
  };

  return { notifications, unreadCount, markAsRead, markAllAsRead };
};

// Mostrar notificación nativa del navegador
const mostrarNotificacionNativa = (notification) => {
  if ('Notification' in window && Notification.permission === 'granted') {
    new Notification(notification.titulo, {
      body: notification.mensaje,
      icon: '/icon.png'
    });
  }
};

// components/NotificationList.jsx
import React from 'react';
import { useNotifications } from '../hooks/useNotifications';

export const NotificationList = ({ projectId }) => {
  const { notifications, unreadCount, markAsRead, markAllAsRead } = useNotifications(projectId);

  return (
    <div className="notification-container">
      <div className="notification-header">
        <h2>Notificaciones</h2>
        <span className="badge">{unreadCount} sin leer</span>
      </div>

      {unreadCount > 0 && (
        <button onClick={markAllAsRead} className="mark-all-btn">
          Marcar todas como leídas
        </button>
      )}

      <div className="notification-list">
        {notifications.map(notif => (
          <div
            key={notif.id}
            className={`notification-item ${!notif.leida ? 'unread' : ''}`}
          >
            <h3>{notif.titulo}</h3>
            <p>{notif.mensaje}</p>
            <small>{new Date(notif.fecha_creacion).toLocaleString()}</small>
            {!notif.leida && (
              <button onClick={() => markAsRead(notif.id)}>
                Marcar como leída
              </button>
            )}
          </div>
        ))}
      </div>
    </div>
  );
};

// composables/useNotifications.js
import { ref, onMounted, onUnmounted } from 'vue';
import { io } from 'socket.io-client';

export function useNotifications(projectId) {
  const notifications = ref([]);
  const unreadCount = ref(0);

  const socket = io('http://localhost:3000');

  const fetchUnreadCount = async () => {
    const response = await fetch('http://localhost:3000/api/notificaciones/contar-no-leidas');
    const data = await response.json();
    unreadCount.value = data.noLeidas;
  };

  const markAsRead = async (notificationId) => {
    await fetch(`http://localhost:3000/api/notificaciones/${notificationId}/leer`, {
      method: 'PATCH'
    });
    unreadCount.value = Math.max(0, unreadCount.value - 1);
  };

  onMounted(() => {
    if (projectId.value) {
      socket.emit('unir_proyecto', projectId.value);
    }

    socket.on('nueva_notificacion', (notification) => {
      notifications.value.unshift(notification);
      unreadCount.value++;
    });

    socket.on('notificacion_proyecto', (notification) => {
      notifications.value.unshift(notification);
    });

    fetchUnreadCount();

    // Solicitar permiso para notificaciones nativas
    if ('Notification' in window && Notification.permission === 'default') {
      Notification.requestPermission();
    }
  });

  onUnmounted(() => {
    socket.off('nueva_notificacion');
    socket.off('notificacion_proyecto');
    if (projectId.value) {
      socket.emit('salir_proyecto', projectId.value);
    }
  });

  return {
    notifications,
    unreadCount,
    markAsRead
  };
}

// services/notification.service.ts
import { Injectable } from '@angular/core';
import { io, Socket } from 'socket.io-client';
import { Observable } from 'rxjs';
import { HttpClient } from '@angular/common/http';

export interface Notification {
  id: number;
  id_proyecto: number;
  titulo: string;
  mensaje: string;
  tipo: string;
  leida: boolean;
  datos?: any;
  fecha_creacion: string;
}

@Injectable({
  providedIn: 'root'
})
export class NotificationService {
  private socket: Socket;
  private baseUrl = 'http://localhost:3000/api/notificaciones';

  constructor(private http: HttpClient) {
    this.socket = io('http://localhost:3000');
  }

  // Observable para notificaciones
  getNotifications(): Observable<Notification> {
    return new Observable(observer => {
      this.socket.on('nueva_notificacion', (data: Notification) => {
        observer.next(data);
      });
      return () => this.socket.off('nueva_notificacion');
    });
  }

  // Unirse a sala de proyecto
  joinProject(projectId: number) {
    this.socket.emit('unir_proyecto', projectId);
  }

  // Salir de sala de proyecto
  leaveProject(projectId: number) {
    this.socket.emit('salir_proyecto', projectId);
  }

  // API REST calls
  getUnreadCount(proyectoId?: number) {
    let url = `${this.baseUrl}/contar-no-leidas`;
    if (proyectoId) url += `?proyectoId=${proyectoId}`;
    return this.http.get<{ noLeidas: number }>(url);
  }

  markAsRead(notificationId: number) {
    return this.http.patch(`${this.baseUrl}/${notificationId}/leer`, {});
  }

  markAllAsRead(proyectoId?: number) {
    return this.http.patch(`${this.baseUrl}/marcar-todas-leidas`, { proyectoId });
  }

  getAllNotifications(proyectoId?: number) {
    let url = this.baseUrl;
    if (proyectoId) url += `?proyectoId=${proyectoId}`;
    return this.http.get<{ total: number; notificaciones: Notification[] }>(url);
  }
}


## ESTRUCTURA DE DATOS
--------------------

Objeto Notificación:

{
  id: number,              // ID único de la notificación

  titulo: string,          // Título de la notificación

  tipo: string,           // Tipo: 'archivo_subido', 'proyecto_actualizado', etc.

## BASE DE DATOS
---------------

Tabla: notificaciones

Campos:
  - id: ID único (PRIMARY KEY, AUTO_INCREMENT)
  - id_proyecto: ID del proyecto relacionado (FOREIGN KEY)
  - titulo: Título de la notificación (VARCHAR 255)
  - mensaje: Mensaje descriptivo (TEXT)
  - tipo: Tipo de notificación (VARCHAR 50)
  - leida: Estado de lectura (TINYINT 1, 0 = no leída, 1 = leída)
  - datos: Datos JSON adicionales (JSON, nullable)
  - fecha_creacion: Timestamp de creación (TIMESTAMP)

Relaciones:
  - FOREIGN KEY (id_proyecto) REFERENCES proyectos(id) ON DELETE CASCADE
